# ASK — sahibine tek soru

**KR-002'yi imzalıyor musun?** Zamanlı ve gözetimsiz koşular (Routines, calistir.sh, cron) yalnız okur ve taslak üretir; bağlayıcı bağlanmaz; yayın, mesaj, ödeme ve dış API yazımı içeren rutin kurulmaz. KP-003 otomatik push kapsam dışı.

Cevap: **go** (yürürlüğe girer) / **kill** / **hold** / **recycle** (değiştirip yeniden getir).
